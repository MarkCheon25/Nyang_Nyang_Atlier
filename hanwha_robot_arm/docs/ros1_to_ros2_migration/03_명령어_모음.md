# HCR-5 ROS1→ROS2 포팅 명령어 모음

모든 명령어는 `bash` 기준. `#`로 시작하는 줄은 각 명령어가 왜 필요한지에 대한 한 줄 설명.

## 1. 환경 확인 (포팅 시작 전 필수)

```bash
echo "ROS_DISTRO=$ROS_DISTRO"                 # ROS1인지 ROS2인지, 어떤 배포판인지 확인
ls /opt/ros/                                  # 시스템에 설치된 ROS 배포판 목록 (ROS1 병행 설치 여부 확인)
ros2 pkg list | grep -i moveit                # MoveIt2 관련 패키지가 이미 설치/빌드되어 있는지 확인
ros2 pkg executables moveit_setup_assistant   # moveit_setup_assistant(GUI) 사용 가능 여부 확인
grep -n "source.*setup.bash" ~/.bashrc        # 추가 오버레이 워크스페이스(예: ~/ws_moveit)가 자동 소싱되는지 확인
```

## 2. 대상 패키지가 ROS1인지 판별

```bash
# 아래 셋 중 하나라도 있으면 ROS1 산출물
grep -n "find_package(catkin" <패키지>/CMakeLists.txt
grep -n "buildtool_depend>catkin" <패키지>/package.xml
find <패키지>/launch -iname "*.launch"        # .launch.py가 아니라 .launch(XML)만 있으면 ROS1
```

## 3. 레거시(ROS1) 패키지를 빌드 대상에서 제외

```bash
touch <ROS1_패키지_경로>/COLCON_IGNORE        # 이 패키지를 colcon이 완전히 무시하게 함 (원래 catkin 에러의 직접적인 해결책)
```

## 4. description 패키지 xacro 검증 (ament_cmake 전환 후)

```bash
source /opt/ros/jazzy/setup.bash
colcon build --packages-select <description_패키지>   # ament_cmake 문법 자체가 맞는지 먼저 단독 빌드로 확인
source install/setup.bash
xacro <install경로>/share/<패키지>/urdf/<로봇>.xacro > /tmp/check.urdf   # xacro가 실제로 파싱되는지, ros2_control 블록이 들어갔는지 확인
grep -A2 "ros2_control" /tmp/check.urdf
```

## 5. MoveIt 설정이 코드 레벨에서 로드되는지 사전 점검 (launch 없이)

```bash
source /opt/ros/jazzy/setup.bash
source ~/ws_moveit/install/setup.bash   # MoveIt2가 별도 오버레이 워크스페이스에 있다면 반드시 같이 source
source ~/ros2_ws/install/setup.bash

python3 -c "
from moveit_configs_utils import MoveItConfigsBuilder
c = (MoveItConfigsBuilder('<robot_name>', package_name='<moveit_config_패키지>')
     .robot_description(file_path='config/<robot>.urdf.xacro')
     .robot_description_semantic(file_path='config/<robot>.srdf')
     .trajectory_execution(file_path='config/moveit_controllers.yaml')
     .planning_pipelines(pipelines=['ompl'])
     .to_moveit_configs())
d = c.to_dict()
print('robot_description len:', len(d['robot_description']))
print('planning_pipelines:', d['planning_pipelines'])
"
# 여기서 에러가 나면 launch까지 갈 필요 없이 yaml/xacro 문제를 먼저 잡을 수 있음
```

## 6. 전체 워크스페이스 빌드

```bash
cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
source ~/ws_moveit/install/setup.bash          # MoveIt2 오버레이가 있다면 항상 먼저 source
colcon build --packages-select <description_패키지> <moveit_config_패키지>   # 관련 패키지만 우선 빌드 (전체 빌드보다 빠름)
# 문제 없으면:
colcon build                                    # 전체 워크스페이스 빌드
```

## 7. MoveIt 데모 실행 (RViz + move_group + 컨트롤러)

```bash
cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
source ~/ws_moveit/install/setup.bash
source install/setup.bash
export DISPLAY=:1                               # 원격/헤드리스 환경이면 RViz를 띄울 디스플레이 지정 필요
ros2 launch <moveit_config_패키지> demo.launch.py
# 종료는 Ctrl+C. 절대 두 번째 터미널에서 같은 launch를 또 실행하지 말 것 (노드/토픽/액션 충돌 → 4번 문제 재현)
```

## 8. 실행 중 상태 확인

```bash
ros2 control list_controllers                   # joint_state_broadcaster / <arm>_controller가 active인지 확인
ros2 topic echo /joint_states --once             # 현재 관절 각도가 의도한 초기 자세로 발행되는지 확인
ros2 node list | grep move_group                 # move_group 노드가 떠 있는지 확인
```

## 9. 좀비/중복 프로세스 정리 (문제 4 같은 충돌이 의심될 때)

```bash
ps aux | grep -E "move_group|rviz2|ros2_control_node|static_transform_publisher|robot_state_publisher" | grep -v grep
# 위에서 나온 PID가 예상보다 많으면(같은 이름 프로세스가 2세트) 전부 kill 후 하나만 재실행
kill -9 <PID1> <PID2> ...
```

## 10. `moveit_py`로 plan+execute 자동 검증 (선택, 자동화 테스트용)

launch(6번)로 `move_group`+컨트롤러가 이미 떠 있는 상태에서 별도 터미널/스크립트로 실행:

```bash
source /opt/ros/jazzy/setup.bash
source ~/ws_moveit/install/setup.bash
source ~/ros2_ws/install/setup.bash
python3 test_plan.py
```

`test_plan.py` 핵심 골격:

```python
import rclpy
from moveit.core.robot_state import RobotState
from moveit.planning import MoveItPy
from moveit_configs_utils import MoveItConfigsBuilder

rclpy.init()
moveit_config = (
    MoveItConfigsBuilder("<robot_name>", package_name="<moveit_config_패키지>")
    .robot_description(file_path="config/<robot>.urdf.xacro")
    .robot_description_semantic(file_path="config/<robot>.srdf")
    .trajectory_execution(file_path="config/moveit_controllers.yaml")
    .planning_pipelines(pipelines=["ompl"])
    .moveit_cpp(file_path="config/moveit_cpp.yaml")   # moveit_py API는 이 파일이 별도로 필요함
    .to_moveit_configs()
)

robot = MoveItPy(node_name="test_plan_py", config_dict=moveit_config.to_dict())
arm = robot.get_planning_component("<planning_group_name>")

robot_state = RobotState(robot.get_robot_model())
robot_state.set_to_random_positions()
arm.set_start_state_to_current_state()
arm.set_goal_state(robot_state=robot_state)

plan_result = arm.plan()
print("PLAN_SUCCESS:", bool(plan_result))
if plan_result:
    print("EXEC_RESULT:", robot.execute(plan_result.trajectory, controllers=[]))
```
