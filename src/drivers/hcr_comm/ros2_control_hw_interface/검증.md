# ros2_control 하드웨어 인터페이스 구성 — 검증 (YYMMDD 세션명)

**집계**: 통과 n / 실패 n / 미검증 n
**환경**: <PC · 컨테이너 이미지 · `<브랜치>@<커밋>` · 실기 유무 — 환경이 다르면 다른 검증>

## 검증표 (행 = 독립 판정 가능한 확인 1건)
| ID | 항목 | 방법 | 기준 | 실측 | 판정 |
|---|---|---|---|---|---|
| V-1 | 빌드 | `colcon build ...` | | | 통과/실패/미검증 |
| V-2 | 플러그인 발견 | `ros2 control list_hardware_components` | | | |
| V-3 | 인터페이스 노출 수 | `ros2 control list_hardware_interfaces` | | | |
| V-4 | 컨트롤러 활성화 | `ros2 control list_controllers` | | | |
| V-5 | 상태 정합 (규약 변환) | 실기 관절값 ↔ `/joint_states` | | | |
| V-6 | `read()` 실효 주기 | `ros2 topic hz /joint_states` | | | |
| V-7 | `write()` 도달 오차 | 실기: <절차 1줄> | | | |
| V-8 | 안전 게이트 (잠금 시 무동작) | 실기: <절차 1줄> | | | |
| V-9 | 통신 두절 거동 | <버스 차단 후 관찰> | | | |

**행 규칙**
- 복수 확인 **병합 금지** — 병합되면 1건의 실패가 통과에 동봉된다
- **행 삭제 금지** — 실행 못 한 행은 실측 칸에 사유 한 단어(실기 필요/접근 불가/소진) + 판정 '미검증'
- 실행 후 추가한 행은 ID 에 `+` 표시
- 기각 조건이 도출 안 되는 기준("0건 이상")은 **등록 무효**
- 판정은 3값, 실측이 기준 밖이면 **자동 실패** (재량 통과 금지)
