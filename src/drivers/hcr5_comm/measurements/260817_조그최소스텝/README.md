# 조그 최소스텝 실측 — 260816-뒤샹 (03pc, 2026-08-17)

> **질문**: `cal_script.md` **N15** 가 짚기 오차 **σ ≤ 0.3mm** 를 요구하는데,
> *"사람이 조그로 0.3mm 를 맞출 수 있는지 미확인"* 으로 남아 있었다. 그것을 실기로 닫는다.
>
> **답**: 조그로는 못 맞춘다 — 그리고 **맞출 필요가 없다.** `movej` 가 **0.045mm 를 오차 0.0000mm**
> 로 낸다. 조그 최소스텝을 좁히는 노력 자체가 불필요해졌다(§4).

측정 자세의 base 축 TCP 수평반경 **519.1mm** → `base 1° = 9.060mm`. 목표 0.3mm = **0.0331°**.

## 0. 결론

| # | 확정된 것 | 근거 |
|---|---|---|
| 1 | **`movej` 는 0.005°(0.045mm)를 오차 0.0000mm 로 낸다** — 8/8 회 지령을 소수점 6자리까지 재현 | §2 |
| 2 | **조그 스텝은 지속시간의 t³·³ 로 커진다** (저크제한 S-curve 램프). 300→500ms 5.6배, 500→1000ms 10배 | §3 |
| 3 | **조그는 사람이 못 맞춘다** — 손가락으로 버튼 누르는 시간의 3제곱으로 결과가 튄다 | §3·§4 |
| 4 | 짚기의 남은 병목은 **명령 분해능이 아니라 사람 눈**이다 | §4 |
| 5 | 🔴 `mqtt_cmd.py jog` 는 `ms ≤ 130` 이면 **ack 를 구조적으로 못 받는다** — 결함 | §5 |

정지 상태 관절값 흔들림이 **전축 0.000000°**(`mqtt_baseline.py` §7)라 위 수치에 센서 잡음이 안 섞였다.

## 3. M2 — 조그 (`jogJoint`, base 축)

| speed | ms | 실측 관절 Δ | 실측 TCP | 예상 대비 | ack |
|---|---|---|---|---|---|
| 1°/s | 100 | 0.000186° | 0.0014mm | 0.2% | ❌ 못 받음 |
| 1°/s | 200 | 0.000660° | 0.0059mm | 0.3% | OK |
| 1°/s | 300 | 0.003006° | 0.0272mm | 1.0% | OK |
| 1°/s | 500 | 0.016799° | **0.1522mm** | 3.4% | OK |
| 1°/s | 1000 | 0.165550° | **1.4999mm** | 16.6% | OK |
| 0.5°/s | 1000 | 0.068692° | 0.6224mm | 13.7% | OK |
| 0.1°/s | 1000 | 0.015103° | 0.1368mm | 15.1% | OK |

### 램프는 t³·³ 다

`speed × time` 예상값을 전혀 안 따라간다. 1°/s 고정으로 시간만 흔들면:

```
t=0.3s → 0.0272mm      t=0.5s → 0.1522mm      t=1.0s → 1.4999mm
          (0.5/0.3)^n = 5.6 → n=3.37          (1.0/0.5)^n = 9.86 → n=3.30
```

**지수 ≈ 3.3** — 저크가 일정한 구간에서 위치가 `t³` 로 가는 S-curve 램프의 서명이다.
`speed` 는 1000ms 에서는 비례해서 먹지만(1.50 : 0.62 : 0.137 ≈ 10 : 5 : 1),
**짧은 조그에서는 램프에 갇혀 거의 안 먹는다**(500ms·1°/s 와 1000ms·0.1°/s 가 둘 다 ~0.14mm).

### 재현성은 조건에 따라 갈린다

| 조합 | 5회 반복 | 산포 |
|---|---|---|
| 1°/s × 500ms | 0.016799° **5회 전부 동일** | **0** (소수점 6자리까지) |
| 0.1°/s × 1000ms | 0.1128 / 0.1287 / 0.1327 / 0.1454 / 0.1499 mm | 폭 **0.037mm** |

앞 조합이 6자리까지 같은 것은 컨트롤러가 **결정론적으로 같은 램프**를 실행한다는 뜻이다.
지터가 있는 것은 로봇이 아니라 **명령이 도착하는 시각** 쪽이다.

### 사후분석 — stop 지연 (`jog_decel.py`, `_260816_실기1차`)

`jog/stop` 발행 후 **230~285ms** 에 잦아든다. 08-16 조그(직교, 125.00, 관절 최대 63°/s)에서
stop 이후 누적 이동 **2.40°**.

> ⚠️ 첫 분석은 정지를 *"연속 3표본 완전 고정"* 으로 잡아 **1210ms / 52°** 라는 값을 냈는데
> **오염된 값**이었다 — 조그 직후 다른 동작이 이어진 회차에서 훨씬 뒤의 정지를 물었다.
> stop 전후 ±0.5초 창의 속도 곡선을 직접 찍어서야 갈렸다. `jog_stop_delay.py` 는 폐기하고
> `jog_decel.py` 만 남긴다.

## 4. 왜 이 질문이 무의미해졌나 — **L21 이 이미 닫혔다**

N15 가 *"사람이 조그로"* 를 전제한 것은 `cal_script.md` **N1**(로봇 자동 이동 봉인) 때문이고,
N1 의 근거는 업무목록 **L21**(`move.joint.velocity` 단위 미확정) 이었다.
**L21 은 2026-08-16 에 닫혔다** — 단위 도/s 확정, `movej` 실기 이동 금지 해제.

즉 **짚기를 조그로 할 이유가 사라진 상태에서 이 질문이 남아 있었다.** M1 이 보인 대로
`movej` 로 짚으면 명령 쪽 오차는 **0**이고, N15 의 σ 에 남는 것은 **사람 눈의 조준** 하나다.

### 🔴 그래서 마커 크기는 아직 못 정한다

N15 의 처방 ㉡(마커를 키운다)을 실행하려면 σ 가 필요한데, 지금 있는 실측은
**조준 반복도 1.041mm**(`260816_펜TCP`)뿐이고 **그 값은 이 질문에 못 쓴다**:

- 그것은 **허공의 고정점을 3D 로** 맞춘 값이다 (자세를 바꿔가며 펜 끝을 한 점에)
- 코너 짚기는 **평면 위 2D 조준**이다 — z 는 작업평면이 잡아 주고, 검은 사각 꼭짓점이라는
  뚜렷한 시각 기준이 있다

1.041mm 를 그대로 대입하면 마커를 **과하게 키우게 된다.** → **M3**(평면 조준 반복도) 가 필요하다.
도구는 [`touch_repeat.py`](touch_repeat.py) 에 준비해 두었다(§6).

### M3 도구의 이동 경로 — IK 왕복이 제자리를 지킨다 (검증됨)

`touch_repeat.py` 는 TCP 를 mm 로 밀기 위해 `현재 TCP + (dx,dy,dz) → IK → movej` 를 탄다.
이 경로가 성립하려면 **아무것도 안 옮겼을 때 IK 가 현재 자세를 그대로 돌려줘야** 한다.
현재 TCP 를 그대로 IK 에 넣어 확인했다:

| 최대 관절 차이 | base 환산 | 판정 |
|---|---|---|
| **0.0001°** | 0.0008mm | ✅ 왕복 안정 — 재는 값(0.3mm)의 1/375 |

⚠️ 다만 IK 에 **낡은 orientation** 을 넘기면 다른 해로 튄다. 실제로 측정 후 자세의 `rz`(−89.574°)를
원위치 복귀 후에 넣었더니 **wrist3 가 −0.43° 돌아간 해**가 나왔다. 도구는 매번 `read_pos()` 로
현재 자세를 읽어 쓰므로 안전하지만, 손으로 `ik` 를 부를 때는 주의할 것.

## 5. 발견한 결함 — `mqtt_cmd.py jog` 의 ack 타임아웃

`ms ≤ 130` 이면 **ack 를 구조적으로 못 받는다.**

```python
budget = ms/1000.0
ack_to = max(0.05, min(2.0, budget))     # ms=100 → 0.1초
```

실측 ack 왕복이 **115~137ms**(README §5.2)라 0.1초 창에는 원리적으로 안 들어온다.
2026-08-02 에 *"ack 대기가 회전시간에 얹히지 않게"* 넣은 가드인데, 그 대가로 짧은 조그에서
**ack 를 포기**하게 되어 있다. 사용자에게는 `⚠ ack 없음 — 명령이 수용됐는지 확인 불가` 로 보인다.

- **로봇은 명령을 받았다** (이번 측정에서 미세하게나마 실제로 움직였다)
- 즉 이 경고는 **거짓 경보에 가깝다** — 그런데 진짜 거부와 구분이 안 된다

📌 처방 후보: `ms` 와 무관하게 ack 를 최소 150ms 는 기다리되 **회전은 계속 두고**
(stop 은 어차피 `finally` 가 보장한다), 경과분을 빼고 남은 시간만 자는 형태.
조그 자체를 미세 위치결정에 안 쓰기로 한 이상 **우선순위는 낮다** → 업무목록.

## 6. 남은 것

- 🔴 **M3 — 평면 조준 반복도 σ** — 마커 크기가 여기 걸려 있다. 도구 `touch_repeat.py` 준비됨.
  `robot/convertJointAngle`(IK, `poseType:"tcp"`) 로 TCP 를 mm 단위로 밀고 `movej` 로 간다
- 🔴 **문서 부채** — `cal_script.md` **N1** 과 `cal_robot.py` `move_to` 봉인이 *"L21 이 닫히기
  전까지 금지"* 인데 L21 은 닫혔다. 코드가 실제보다 보수적으로 묶여 있다
- 🟡 `movej` 미세스텝의 **진짜 하한 미측정** — 0.005° 에서 멈췄다(요구를 이미 압도해서)
- 🟡 조그 ack 타임아웃 결함(§5)
- 🟡 이 측정은 **base 축 한 축**이다. 반경이 크게 다른 축(J5·J6)에서 같은지는 미확인 —
