현재 한글입력 실패

Ubuntu 22.04.5 LTS 카카오톡 설치 가이드
STEP 1 — 32비트 아키텍처 활성화 및 wget 설치
bashsudo dpkg --add-architecture i386
sudo apt install -y wget
STEP 2 — WineHQ GPG 키 및 저장소 추가
bashsudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo wget -NP /etc/apt/sources.list.d/ https://dl.winehq.org/wine-builds/ubuntu/dists/jammy/winehq-jammy.sources
STEP 3 — 패키지 업데이트 및 Wine 설치
bashsudo apt-get update
sudo apt install -y --install-recommends winehq-stable
STEP 4 — Wine 초기 설정
bashwinecfg

설정 창에서 Windows 버전 → Windows 10 선택
라이브러리 탭 → d3dx11_43 추가 후 확인

STEP 5 — 카카오톡 설치파일 다운로드

https://www.kakaocorp.com/page/service/service/KakaoTalk
→ 다운로드 → Windows 클릭

STEP 6 — 카카오톡 설치 실행
bashcd ~/Downloads
LANG="ko_KR.UTF-8" wine KakaoTalk_Setup.exe
STEP 7 — 한글 깨짐 시 실행 방법
bashLANG="ko_KR.UTF-8" wine "C:/Program Files/Kakao/KakaoTalk/KakaoTalk.exe"
